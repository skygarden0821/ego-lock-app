# EGO LOCK — スプレッドシート＆カレンダー連携（GAS）

非公開のスプレッドシートを**公開せずに**、必要な数値だけをアプリに渡す中継（Google Apps Script）。
Yoshiの実シート構成に合わせて `Code.gs` は設定済み。基本そのままデプロイするだけ。

## 取り込む数値（対応表）

| アプリの表示 | 取得元シート | 場所 |
|---|---|---|
| LINE追加 / AD / 契約（日次） | 「日次進捗」タブ | A〜D列（日付 / LINE追加数 / AD数 / 契約数）を日次で集計 |
| お月謝＝月商（月次） | 各月タブ `202601`〜 | 「回収」列の合計（＝支払完了の費用合計） |

これらが HOME 最上部「今年の目標（月商）」「今月の目標（契約 / AD / ライン）」に反映される。

## セットアップ手順

1. https://script.google.com →「新しいプロジェクト」→ 出ているサンプルを全消し。
2. `Code.gs` の中身を全部貼り付け。
3. 合言葉を**スクリプトプロパティ**に入れる（コードには書かない）。**必須。**
   左の **⚙ プロジェクトの設定 > スクリプト プロパティ > スクリプト プロパティを追加** で
   プロパティ名 `EGOLOCK_KEY`、値に好きな合言葉を入れて保存。※アプリにも同じ値を入れる。
   - これが未設定だと、シート同期（doGet）もカレンダー連携（doPost）も
     `合言葉が未設定です` を返して動かない。空のまま使うことはできない。
   - `sheetId` は2つとも設定済み。タブ名も「日次進捗」設定済み。基本さわらない。
4. 関数プルダウンで **`_test`** を選び ▶ 実行 → 初回は権限を許可 → 実行ログに
   `{"ok":true, "month":{...}, "monthsRevenue":{...}}` が出れば成功。
5. 右上 **デプロイ > 新しいデプロイ > 種類:ウェブアプリ**
   - 実行するユーザー: **自分**
   - アクセスできるユーザー: **全員**（ブラウザから読むため必須。KEYで保護）
6. 発行された `…/exec` URL をコピー。

## アプリ側

`記録 > 設定 > シート連携` に：
- **GAS URL**: `…/exec`
- **連携キー**: スクリプトプロパティ `EGOLOCK_KEY` と同じ文字（**必須**。空だと `bad key` で弾かれる）
- **自動同期**: ON（起動時・復帰時に随時取得）
- **今すぐ同期**: 手動取得

## 返すJSON

```json
{
  "ok": true,
  "updated": "2026-07-07T09:00:00+09:00",
  "count": 551,
  "month": { "lineAdds": 11, "ad": 1, "contracts": 2, "revenue": 529900 },
  "days": { "2026-07-01": { "lineAdds": 4, "ad": 0, "contracts": 1 } },
  "monthsRevenue": { "2026-07": 529900, "2026-06": 000000 }
}
```

## つまずいたら

- **数値が0/ズレる（LINE・AD・契約）**: 「日次進捗」タブの見出しが `日付 / LINE追加数 / AD数 / 契約数` か確認。違えば `CONFIG.DAILY.cols` の右側を実際の見出しに合わせる（部分一致でOK）。
- **お月謝が0**: 各月タブ名が `202607` 形式か、「回収」列があるか確認。列名が違えば `CONFIG.OTSUKI.revenueHeader` を変更。回収列が空でも「支払完了」の費用を自動合算するフォールバックあり。
- **`合言葉が未設定です`**: スクリプトプロパティ `EGOLOCK_KEY` が空。値を入れる（⚙ プロジェクトの設定）。再デプロイは不要。
- **`bad key`**: アプリの連携キーと スクリプトプロパティ `EGOLOCK_KEY` を一致させる。アプリ側の連携キーが空のときもこれが出る。
- **Failed to fetch / CORS**: デプロイのアクセス範囲を「全員」に。URL は `/exec` で終わること。
- シート構成を変えたら**新しいバージョンで再デプロイ**。

# カレンダー連携（2026-09 追加）

同じGAS（同じ `/exec` URL）に、Googleカレンダー連携を足した。アプリとの間はこう動く。

| アプリでやること | カレンダーで起きること |
|---|---|
| 時刻を入れたタスクを作る／時刻を変える | 予定が作られる／動く（判断系は紫、通常は水色） |
| 完了にする | タイトル先頭に ✅、色がグレー。早く終わればその時刻で予定を締める |
| 完了を取り消す | 元のタイトル・色・長さに戻る |
| 明日へ送る／削除する／時刻を消す | 予定が動く／消える |

| カレンダーでやること | アプリで起きること |
|---|---|
| 予定をドラッグして時刻や長さを変える | タスクの時刻・所要分が変わる |
| タイトルを書き換える | タスク名が変わる |
| タイトル先頭に ✅ を付ける | タスクが完了になる |
| 予定を削除する | タスクは残り、時刻が外れる（「カレンダーで削除」と表示） |

EGO LOCKが作った予定には目印（タグ `egolock`）が付く。目印のない予定は、読むだけで一切変更・削除しない。
空き時間の計算では、終日予定・12時間以上の予定・辞退した予定と、アプリ設定の「無視する予定名」（初期値 `予約NG`）は数えない。

## 更新手順（すでにシート連携をデプロイ済みの場合）

URLを変えずに更新する。

1. script.google.com でこのプロジェクトを開き、`Code.gs` の中身をリポジトリの最新版に全部貼り替える。
2. **スクリプトプロパティ `EGOLOCK_KEY` に合言葉を必ず入れる**
   （**⚙ プロジェクトの設定 > スクリプト プロパティ**）。
   合言葉が空だと、シート同期もカレンダー連携も動かない。
   合言葉はコードに書かないので、`Code.gs` を貼り替えても消えない。
3. 関数プルダウンで **`_test`** を選び ▶ 実行。カレンダーの権限許可が出るので許可する。
   実行ログの2行目に `"writable":true` が出ればOK。
4. 右上 **デプロイ > デプロイを管理 > 鉛筆（編集）> バージョン：新しいバージョン > デプロイ**。
   ※「新しいデプロイ」を押すとURLが変わるので注意。

まだ一度もデプロイしていない場合は、上の「セットアップ手順」を先にやる。

## 書き込み先カレンダー

`CONFIG.CAL.writeId` が書き込み先（初期値は `X1_九之池`）。GASは「デプロイしたアカウント」の権限で動く。

`_test` で `"writable":false` になったときは、どちらかにする。

- **A.** `X1_九之池` を持っているアカウントのGoogleカレンダー設定で、GASを動かしているアカウントへの共有権限を「**予定の変更**」にする。
- **B.** `writeId` を、GASを動かしているアカウントが持つカレンダーに変える。例：`事業タスク`
  `4bf6d6f8be863db221d3c6aadb7d88da399f9f55bc9ef16fea3217b428a75358@group.calendar.google.com`
  この場合も `readIds` は `X1_九之池` のままにしておけば、空き時間は仕事の予定から計算される。

`readIds` には空き時間の計算に使うカレンダーを複数入れられる（私用の予定も避けたいなら追加する）。

## アプリ側

`記録 > 設定`：
1. **シート連携（GAS）** の URL と連携キー（スクリプトプロパティ `EGOLOCK_KEY` と同じ文字。**必須**）を入れる。
2. **カレンダー連携（Google）** を ON → **接続テスト** で「書き込める。準備OK」と出れば完了。
3. 作業時間帯（初期 9:00〜21:00）と、予定前後の余白（初期10分）は好みで変える。

同期はアプリを開いたとき・戻ったとき・やることリストを開いたときに自動で走る（1分に1回まで）。オフラインでの変更は「送信待ち」に溜まり、つながったときにまとめて送る。

## つまずいたら（カレンダー）

- **合言葉が未設定です**：スクリプトプロパティ `EGOLOCK_KEY` に文字を入れる（⚙ プロジェクトの設定）。再デプロイは不要。
- **bad key**：アプリの連携キーと スクリプトプロパティ `EGOLOCK_KEY` が一致していない。
- **書き込み先カレンダーが見つかりません**：`writeId` のカレンダーが、GASを動かしているアカウントから見えていない。
- **読めるが書き込めない**：上の「書き込み先カレンダー」の A か B。
- 変更がアプリに戻らない：自動同期は1分に1回まで。やることリストの「同期」ボタンで即時に取りに行ける。
